# Fiscalint

**2026 新北市 AI 智慧城市黑客松競賽｜教育局組**（參賽題目：小小守護員 Smart Watchdog）

AI × 鑑識會計，打造教保機構智慧風險預警管理系統。整合公開財務、裁罰、評鑑、收費與社群輿情資料，用可量化、可解釋的風險評分模型，把「事後被動稽查」提前為「事前主動示警」。

## 專案目標

- 從公開資料中有效篩選出高風險教保機構
- 縮短預警時間，從事後稽查提前為事前示警
- 降低稽查人力負擔，讓有限人力精準投放

## 風險是怎麼判定的（白盒子，可解釋）

我們的風險分數不是黑盒子。每一間幼兒園的總風險分 (0–100) 由三個分項加權而成，每項都能攤開解釋：

```
總風險分 = 財務異常 ×50%  +  裁罰紀錄 ×34%  +  評鑑結果 ×16%
```
（原設計含輿情負面 ×10%，但輿情資料源尚未接入真實爬蟲/NLP，為避免以佔位值稀釋真實訊號，暫不納入計分，原 10% 依比例分配給其餘三項：45:30:15 → 50:34:16。接入真實輿情後可再加回並重新分配權重。）

### 分項一：財務異常分（最核心，50%）
由「四層鑑識會計方法」疊合，全部有學術文獻佐證（見 `docs/methodology.md`）：

| 方法 | 抓什麼 | 佔財務分 |
|------|--------|---------|
| 班佛定律 (Benford's Law) | 逐筆明細金額的首位數分布是否異常（數字造假傾向） | 25% |
| Beneish M-Score 改良版 | 收入與支出成長背離、應計項目異常（盈餘操縱） | 20% |
| Isolation Forest + SHAP | 多維財務特徵的整體異常（非監督式 AI） | 25% |
| 收支比離群 (IQR) | 支出/收入比在全體同儕中是否離群 | 10% |
| 跨年度突變 | 收支較上年度暴增暴減 | 10% |
| 賸餘短絀率 | 本期短絀占收入比（基金被侵蝕） | 10% |

**多層交叉驗證**：多個獨立方法同時指向同一間園時，風險判定最可信。

**交叉指標關係加成（財務分之上額外加分，鑑識會計核心——看指標間關係而非單一門檻）**：
- 每生單位收入偏離同儕（收入 ÷ 核定人數，同類型比較）：+12
- 每生單位成本偏離同儕（支出 ÷ 核定人數，雙尾 |z|≥1.5）：+10 — 直接命中命題「財報 × 幼兒人數交叉分析」，偏高恐浮編、偏低恐排擠品質
- 收入-支出成長背離（收支應同步成長，背離即結構突變）：+10

缺核定人數資料的園（目前非營利園）人數相關加成自動不觸發（誠實不硬編）。

### 分項二～三
- **裁罰紀錄 (34%)**：改用「裁罰性質分類 + 嚴重度」而非純次數（安全 90、收費 80、人力 70、教保 55、行政 35），以主類別嚴重度為基底、每多一次裁罰 +10（上限 100）。這樣「2 次收費違規」會明顯重於「2 次行政缺失」，符合鑑識會計「看違規性質而非只看次數」。無事由文字時以中性值 50 為基底遞增（1 次=50、2 次=60…）。
- **評鑑結果 (16%)**：優=0、良=20、乙=40、待改進=90，缺資料=中性 30。

> 原設計的第四分項「輿情負面」因資料源尚未接入，暫不納入計分（見上方公式說明）。

### 風險等級（兩種分級並存，可對照）
本系統目的是「排出稽查優先序」，因此主要採**相對分級**，並保留絕對門檻供對照：

- **相對分級（主用，`risk_level`）**：以同儕分布做百分位分級 — 前 15% 為高風險、次 35% 為中風險、其餘低風險。**並依機構類型（公校／非營利）各自分級**：兩類機構財務結構與可得資料層不同（非營利園無逐筆明細、缺班佛分項，財務分會被系統性低估），若混在同一把尺比較，非營利園會被不公平地壓在後段；分類型內部比較才是正確的同儕比較（peer benchmarking，見方法論）。確保稽查資源能投向「各類型中相對最需關注」的園。
- **絕對分級（對照，`risk_level_abs`）**：≥60 高、≥35 中、其餘低。用於檢視「以固定門檻看，是否有絕對意義的高風險」。

> 說明：目前絕對分級下多數落在中低風險，反映公立園整體相對規矩；相對分級則明確指出「該優先查哪幾間」。真實裁罰資料接入後，絕對高風險園會浮現。

### 財務面最異常（純財務訊號，不含裁罰）
- **瑞芳幼兒園**：支出達收入 1.69 倍，短絀近 300 萬，財務分 82.8（全體最高）
- **金山幼兒園**：收支比 1.13，支出年減 31% 波動大
- **三芝幼兒園**：班佛偏離度 0.064（全體最高），數字分布最異常

### 判定邏輯範例（以林口幼兒園 54.9 分為例）
```
財務異常 35.8 ×0.50 = 17.9
裁罰       90  ×0.34 = 30.6   ← 2 次「收費違規」(收費類嚴重度 80，+1 次 = 90)
評鑑(乙)   40  ×0.16 =  6.4
─────────────────────────
總分 = 54.9（相對分級：高風險）
```
稽查員一看就知道：林口的高分主要來自「裁罰紀錄」與「財務異常」，且裁罰屬「收費違規」（高嚴重度），應優先查這兩塊。

## 模型效能（以示範裁罰資料驗證）
- **AUC-ROC = 0.976**（辨識能力優異，>0.9）
- **Recall = 1.0**（所有被裁罰的園都被歸入較高風險，零漏抓）
- **相關係數 = 0.741**（風險分與裁罰次數高度正相關）
- **權重敏感度 Spearman = 0.869～0.967**（大幅改變權重，高風險排名仍高度穩定，結論穩健）
