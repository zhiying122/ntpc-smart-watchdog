# 小小守護員 Smart Watchdog

**2026 新北市 AI 智慧城市黑客松競賽｜教育局組**

AI × 鑑識會計，打造教保機構智慧風險預警管理系統。整合公開財務、裁罰、評鑑、收費與社群輿情資料，用可量化、可解釋的風險評分模型，把「事後被動稽查」提前為「事前主動示警」。

## 專案目標

- 從公開資料中有效篩選出高風險教保機構
- 縮短預警時間，從事後稽查提前為事前示警
- 降低稽查人力負擔，讓有限人力精準投放

## 風險是怎麼判定的（白盒子，可解釋）

我們的風險分數不是黑盒子。每一間幼兒園的總風險分 (0–100) 由四個分項加權而成，每項都能攤開解釋：

```
總風險分 = 財務異常 ×40%  +  裁罰紀錄 ×30%  +  評鑑結果 ×15%  +  輿情負面 ×15%
```

### 分項一：財務異常分（最核心，40%）
由「四層鑑識會計方法」疊合，全部有學術文獻佐證（見 `docs/methodology.md`）：

| 方法 | 抓什麼 | 佔財務分 |
|------|--------|---------|
| 班佛定律 (Benford's Law) | 逐筆明細金額的首位數分布是否異常（數字造假傾向） | 25% |
| Beneish M-Score 改良版 | 收入與支出成長背離、應計項目異常（盈餘操縱） | 20% |
| Isolation Forest + SHAP | 多維財務特徵的整體異常（非監督式 AI） | 25% |
| 收支比離群 (IQR) | 支出/收入比在全體同儕中是否離群 | 10% |
| 跨年度突變 | 收支較上年度暴增暴減 | 10% |
| 賸餘短絀率 | 本期短絀占收入比（基金被侵蝕） | 10% |

**多層交叉驗證**：多個獨立方法同時指向同一間園時，風險判定最可信。

### 分項二～四
- **裁罰紀錄 (30%)**：0 次=0 分、1 次=50、2 次=80、3 次以上=100。
- **評鑑結果 (15%)**：優=0、良=20、乙=40、待改進=90。
- **輿情負面 (15%)**：網路負面評論比例。

### 風險等級
- 🔴 高風險：≥ 60 分
- 🟡 中風險：35–59 分
- 🟢 低風險：< 35 分

## 目前判定結果（以最新年度、含示範裁罰資料）

> 註：裁罰/評鑑目前為示範資料，實際應用時以全國教保資訊網即時資料為準。
> 以下為 22 間新北市立幼兒園的實際運算結果。

### 需優先關注的學校（中風險）

| 排名 | 學校 | 總分 | 等級 | 主要風險訊號 |
|------|------|------|------|-------------|
| 1 | 新北市立林口幼兒園 | 48.2 | 🟡中 | 裁罰 2 次 + 收支超支 7.3% + 財務異常 |
| 2 | 新北市立瑞芳幼兒園 | 37.3 | 🟡中 | 收支比 1.69（嚴重入不敷出）+ Beneish 92 分 + 孤立森林 100 |

### 財務面最異常（雖裁罰資料未接，財務訊號突出）
- **瑞芳幼兒園**：支出達收入 1.69 倍，短絀近 300 萬，財務分 74.5（全體最高）
- **金山幼兒園**：收支比 1.13、財務分 67.4，Beneish 39.8
- **三芝幼兒園**：班佛偏離度 0.058（全體最高），數字分布最異常

### 判定邏輯範例（以林口幼兒園 48.2 分為例）
```
財務異常 38.0 ×0.40 = 15.2
裁罰(2次)  80  ×0.30 = 24.0
評鑑(乙)   40  ×0.15 =  6.0
輿情       20  ×0.15 =  3.0
─────────────────────────
總分 = 48.2（中風險）
```
稽查員一看就知道：林口的高分主要來自「裁罰紀錄」與「財務異常」，應優先查這兩塊。

## 模型效能（以示範裁罰資料驗證）
- **AUC-ROC = 0.918**（辨識能力優異，>0.9）
