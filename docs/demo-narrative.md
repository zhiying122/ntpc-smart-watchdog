# Demo 主線與創意主軸（Creative Spine × 需求對映）

小小守護員 Smart Watchdog — 2026 新北市 AI 智慧城市黑客松（教育局組）

> 用途：釘住「創意 + 實用」的敘事主線，讓 Demo 有一條清楚的故事，避免失焦。
> 原則：以現有需求為本，收斂不擴張。所有畫面／功能都必須為「凸顯三大創意」服務；
> 不服務主軸的功能一律不做（對齊 steering：反 AI 生成風、政府級可信度優先）。

## 一句話定位

別人做幼兒園風險評分，我們做「AI 稽查官」——用審計界抓弊案的**鑑識會計**算出可解釋的風險分數，
用犯罪學的**破窗效應**捕捉惡化趨勢，連**沒有財報的附設幼兒園**都能評，再讓生成式 AI 產出稽查建議，
讓每個稽查員產能放大十倍。

## 三大創意主軸（記憶點，全部用現有需求即可達成）

### 創意 1：鑑識會計搬進幼兒園（護城河）
- **是什麼**：班佛定律抓數字造假、Beneish、人事費可負擔性勾稽、跨年度突變。
- **為何是創意**：90% 隊伍會做「風險評分」，不會有人講「鑑識會計」。這是審計界抓弊案的方法遷移到教保監理。
- **對映需求**：R7（鑑識會計核心）、R8（異常偵測）、R13（同儕比較）。
- **對映任務**：Task 2、3、4（已完成核心；2.3b 人事勾稽待做）。
- **Demo 台詞**：「這間園的決算數字，第一位數分布不符合班佛定律——正常財務數字不會長這樣。」

### 創意 2：破窗效應 + 時效衰減（犯罪學搬進稽查）
- **是什麼**：頻繁、近期、未改善的小違規，用破窗理論 + 再犯風險時效衰減指數式累積成裁罰分項。
- **為何是創意**：把犯罪學／再犯預測的方法論遷移到教保稽查，跨領域，可辯護（有論文依據）。
- **對映需求**：R25（破窗效應累犯加權）。
- **對映任務**：Task 4.5（待做）。
- **Demo 台詞**：「這間園每一次都是小違規，但頻率越來越高、越來越近——破窗效應告訴我們，這是憾事的前兆。」

### 創意 3：雙評分檔——連沒財報的附幼都能評（實用性創意）
- **是什麼**：財務鑑識園（有決算，四分項）vs 行為監測園（附幼無財報，裁罰／評鑑／輿情），誠實標示方法別。
- **為何是創意**：別人只評得了有財報的園；我們用國際主管機關的「合規—品質」評分法（Fiene 序位計分、差異化監測、RBI）補上無財報缺口，涵蓋不再受限。
- **對映需求**：R26（機構涵蓋範圍與雙評分檔）、R18（資料可信度）、R10.5（缺分項中性處理）。
- **對映任務**：待補（見 tasks.md 新增 Task 6.1d）。
- **Demo 台詞**：「國小附幼沒有獨立財報——別的系統到這裡就沒轍了。我們切換到行為監測評分檔，一樣算得出可解釋分數。」

## Demo 主線（一條龍，對映使用者旅程）

政府視角 → 稽查員視角 → AI 輔助，三步走，全部是已完成的 P0 功能：

1. **全局（Gov_Console，R2）**：打開風險地圖，紅黃綠一眼看出哪一區最該查。
   點行政區排名 → 高風險機構排名前 20。
   *凸顯*：實用（稽查員排路線精準投放人力）。

2. **下鑽（Inspector_Workspace，R5 + R11）**：點一間高風險園進工作台。
   - 雷達圖攤開四分項（財務／裁罰／評鑑／輿情）——**這是白盒子創意的視覺高光**。
   - 點財務分項 → 證據鏈下鑽：分數 → 班佛/Beneish 特徵 → 原始決算數字 → PDF 來源頁。
   *凸顯*：創意 1（鑑識會計）+ 可解釋（政府敢用的前提）。

3. **趨勢（Timeline，R12 + 創意 2）**：時間軸標出「情勢惡化變化點」與破窗累積。
   *凸顯*：創意 2（破窗效應）+ 事前預警。

4. **無財報園切換（R26 + 創意 3）**：切到一間國小附幼，展示評分檔自動切換為「行為監測」，
   畫面標示「無獨立財報，僅基於合規／評鑑／輿情」。
   *凸顯*：創意 3（涵蓋廣、誠實揭露）。

5. **AI 建議（AI_Copilot，R15）**：Bedrock 產出「這間園建議查什麼」的稽查建議。
   *凸顯*：降低人力、AI 用於生成而非計分（責任 AI）。

## 刻意不做（收斂邊界，避免失焦與炫技）

| 不做 | 原因 |
|------|------|
| 即時爬 FB/IG 社群 | 平台反爬、Demo 當天易掛、違反 ToS；改用新聞 live + 社群快照 NLP |
| 知識圖譜互動炫圖（R14）| P1，先文件化即可，互動視覺化偏炫技、非主軸 |
| 各種動畫／發光效果 | 違反 steering 反 AI 生成風；唯一例外為側欄 System Status 綠點 |
| 為附幼即時抓全國教保資訊網 | 待主辦方確認範圍再做，避免白工；先建評分檔機制 |
