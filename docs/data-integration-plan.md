# 資料介接與備援計畫書

**系統**：Fiscalint 教保機構智慧風險預警管理系統
**適用對象**：新北市政府教育局（系統移交／上架審查用）
**文件性質**：政府級系統移交必備文件，說明資料來源、介接方式、更新頻率、
備援機制與資料治理。

---

## 1. 目的

本文件說明 Fiscalint 系統所使用之資料來源、介接方式與備援策略，回應題目
痛點 1「資料分散與整合困難、缺乏即時整合機制」。系統設計原則為
**動態整合官方開放資料 + 本地快取 + 離線備援**，確保外部來源異常時服務不
中斷（Reliability by Design）。

### 2.1 誠實標註原則（責任 AI / 資料治理）

- g0v 開源專案（開發者江明宗 kiang）之 JSON 為**二手整理資料**，非官方保證
  正確性之來源。系統一律標註「資料來源：全國教保資訊網（教育部），經 g0v
  開源專案（江明宗）整理備份」，並記錄抓取時間。
- 上架前應抽查 5–10 筆裁罰與收費資料，與官方查詢頁面核對一致性。
- 正式部署應優先改接官方 API（data.gov.tw dataset 6086、新北市 OpenAPI）。

## 3. 介接架構

```
[ 官方開放資料源 ]
  ├─ preschools.json（基本資料/收費/核定人數，GeoJSON）
  └─ punish_all.json（裁罰紀錄，JSON）
            │  HTTPS GET（timeout 保護）
            ▼
[ 動態資料連接器 src/live_source.py ]
  ├─ 即時抓取成功 → 解析正規化 → 寫入本地快取 → 供風險引擎/UI 使用
  └─ 抓取失敗（無網路/逾時/來源異動）→ 退回最近一次本地快取（離線備援）
            │
            ▼
[ 風險引擎 src/ ]  →  [ 契約檔 data/processed/*.csv ]  →  [ 三入口 UI ]
```

### 3.1 即時抓取

- 由 UI「同步最新資料」按鈕或排程觸發 `live_source.load_live_dataset()`。
- 所有 HTTP 請求設 `timeout`（預設 30 秒），避免無限等待。

### 3.2 快取與離線備援

- 抓取成功即寫入 `data/cache/`（不進版控，可重新產生）。
- 抓取失敗自動退回快取；`FetchResult` 明確回報 `is_live` / `used_fallback` /
  `error`，UI 誠實顯示「即時串接」或「離線快取備援」。
- 連快取都不存在時，系統退回內建靜態契約檔，仍可 Demo。

### 3.3 更新頻率與排程建議（正式部署）

- 建議以排程器（Windows 工作排程／cron／雲端 EventBridge）每日呼叫
  `load_live_dataset()`，構成「隨資料更新自動重新評估風險與預警」的即時
  預警系統，無需改動連接器邏輯。

## 4. 資料品質與實體解析

- 裁罰紀錄多以「行為人／負責人」個人姓名為鍵，與機構的對應需經負責人欄位
  或名稱比對，屬不確定比對；系統對無法可靠判定者標示「待人工確認」而非
  強制合併（見 `src/entity_resolver.py`）。
- 每一機構計算資料可信度分數（`src/confidence.py`），低可信度資料不得單獨
  推高風險（責任 AI）。

---

## 5. 資安與合規

- 所有外部請求為唯讀 HTTPS GET，不傳送任何專案資料或個資至第三方。
- 不使用任何 API 金鑰；如未來改接需金鑰之官方 API，金鑰一律置於 `.env`，
  以 `os.environ` 讀取，禁止寫死（見 `scripts/check_secrets.py`）。
- 公務後台與公眾查詢網採系統切分（獨立進入點、生產環境獨立網域／主機隔離）。
- 家長端資料於資料層即去識別化投影，不含任何風險分數（`permissions.authorize_dataframe`）。

---

## 6. 失效情境與因應（Failure Modes）

| 情境 | 系統行為 | 使用者可見 |
|------|---------|-----------|
| 外部來源逾時 | 退回本地快取 | 標示「離線快取備援」+ 抓取時間 |
| 外部來源格式異動 | 解析容錯，退回快取 | 同上 + 錯誤說明 |
| 無網路且無快取 | 退回內建靜態契約檔 | 提示資料為內建示範資料 |
| 部分欄位缺值 | 該欄位標「查無公開資料」，不以推估替代 | 家長端誠實顯示 |

## 7. 驗證

- 連接器解析、快取、離線備援、狀態旗標皆有單元測試（`tests/test_live_source.py`）。
